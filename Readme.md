# GoodbyeDPI-baomod

Bypass the Vietnam Steam block without needing a VPN! Based on [GoodbyeDPI](https://github.com/ValdikSS/GoodbyeDPI), modded by Bao.

## 📥 Download and Install
1. Go to the [Releases page](link-to-your-github-releases) and download the latest `.zip` file.
2. Extract the folder to your PC.
3. Right-click `install.exe` and run as Administrator.


## 🔓 Want to unblock another site?
Just add the domain to `blacklist.txt` and reinstall.
