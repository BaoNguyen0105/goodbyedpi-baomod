# GoodbyeDPI-baomod

Bypass the Vietnam Steam block without needing a VPN! Based on [GoodbyeDPI](https://github.com/ValdikSS/GoodbyeDPI), modded by Bao.

### Quick Start
- **Install:** Right-click `install.cmd` -> Run as administrator. Enjoy Steam!
- **Uninstall:** Right-click `uninstall.cmd` -> Run as administrator to remove it.

### Want to unblock another site?
Just add the domain to `blacklist.txt` and restart the tool.
